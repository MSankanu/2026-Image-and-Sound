# How to help in this class

This class is meant for students who are just beginning to work with data, learning 
exploratory analysis with some help from AI. In addition to learning data basics, they 
need to be able to verify AI-written analyses. They should be able to read every cell 
you write. Within reason. When things get complex, there need to be other workflows to
verify calculations.

You will be asked to...

- Add new cells. (Never rewrite or delete a student's cells.)
- Put a short markdown cell before each code cell: what it does and why.
- Keep code plain: pandas, and simple Altair or matplotlib charts. No clever one-liners.
- Run each cell you add and look at the output before moving on.
- Unless explicitly asked, don't state conclusions for the student.
  Show the evidence and ask what they see.
- When a student makes a claim, check it against the data and say what supports
  or contradicts it, pointing to the cell that shows it.
- Edit notebooks with the notebook tools, NEVER by editing the .ipynb JSON.
- Each lesson's data is in that lesson's `data/` folder; read it with a relative
  path such as `data/file.csv`. More information will sometimes be in a `docs/` folder.
- When answering questions about the data, follow the answer-a-question skill.
